# Portfolio content checklist

Use this checklist to ensure the portfolio tells a credible story without inventing evidence.

## Required foundations
- [ ] Name and accurate current headline
- [ ] One-sentence value proposition for the primary audience
- [ ] Short, factual bio that clarifies career direction and strengths
- [ ] Verified contact method and social links
- [ ] Clear primary call to action

## Selected work
For every featured project, capture:
- [ ] Project name and type
- [ ] Problem or goal
- [ ] The person's role and contribution
- [ ] Process, tools, or key decisions
- [ ] Outcome or learning (only real, verifiable claims)
- [ ] Repository, live demo, case-study, or Figma link if available
- [ ] Image / visual and useful alt text

## Audience adaptation
### Employers
- [ ] Clear technical and design strengths
- [ ] Evidence of ownership, collaboration, and problem solving
- [ ] Resume or GitHub link where available

### Freelance clients
- [ ] Services or engagement types offered
- [ ] Clear client-friendly project outcomes
- [ ] Simple inquiry path and expected next step
- [ ] No unapproved client names, logos, or testimonials

## Content safety
- [ ] No invented employers, metrics, clients, testimonials, credentials, or outcomes
- [ ] No private contact information beyond what the owner authorizes
- [ ] Placeholders are explicitly labelled for later replacement
